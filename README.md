## ◈ What is JARVIS?

JARVIS is a personal AI assistant designed to bring intelligent conversation, voice interaction, desktop automation, and productivity tools together in one unified system.

## ◈ Features

| Feature | Description |
|---|---|
|  Voice AI | Natural voice interaction |
|  Memory | Context-aware persistent memory |
|  Desktop | Approved computer automation |
|  Mobile | Companion device integration |
|  Multi-model | Local and cloud AI backends |
|  Automation | Multi-step workflows |
